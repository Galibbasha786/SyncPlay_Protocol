# Reusable Prompt for Each Development Session

Continue SyncPlay development using `AGENTS.md` and `docs/ai-context/` as the source of truth.

Current phase: [WRITE PHASE]
Current milestone: [WRITE MILESTONE]
Task for this session: [ONE SMALL TASK]

Before editing:
1. Inspect the relevant current files and tests.
2. Restate the expected behavior and constraints.
3. List exact files you plan to create/change.
4. Identify any contract mismatch or unresolved decision.
5. Propose tests and verification commands.

Then implement only this task after approval (or immediately if I explicitly say to implement now). Do not expand scope.

After implementation:
- Run the relevant tests/typecheck/lint/build.
- Report exact commands and results, including failures.
- Summarize changed files and design choices.
- State limitations and next smallest task.
- Update docs/decision log if an approved decision changed.
